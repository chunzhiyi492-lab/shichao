# 拾潮

给同人创作者用的私人灵感与设定工作台，只处理创作者自己写的东西。

> 原作是月亮，你的故事是潮水。

## 功能

- **潮位首页**：一片抽象海岸线，水位随未回收的伏笔数升降；每条没回收的伏笔是水下的一块礁石，只露模糊轮廓和标题，点开看详情；标成「已回收」，水位轻轻下降，礁石慢慢露出水面
- **贝壳盒**：灵感速记（文字、标签、心情、日期），可搜索、可按心情与标签筛
- **设定卡**：人物 / 关系 / 世界观卡片，字段自己加，关系用可拖动的节点图看连线
- **伏笔**：标题、说明、关联设定卡，状态分已埋下 / 已回收 / 已放弃
- **AI 工具**：一致性检查（按设定卡指出草稿里的前后矛盾）、灵感提问（按选中的笔记提 5 个开放式问题）；每次调用前弹确认框并要求勾选「这是我自己的原创文字」
- **月相**：登记原作，只记名称、链接和你自己写的 200 字内摘要，另有原作者二创规则手动勾选清单
- **潮汐表**：每天自己登记一个字数，一年是一条潮汐线，连续写的天数也在这里数
- **数据**：导出 JSON 与 Markdown、导入自己导出的 JSON、清空全部数据

## AI Key 设置

1. 打开设置页，找到「AI 设置」
2. 粘贴你自己的 Key（OpenAI 兼容格式的服务都可用）
3. 服务地址、模型留空时用默认值（`https://api.openai.com/v1` / `gpt-4o-mini`），也可以改成你自己的
4. 点「保存 AI 设置」

Key 只存在你自己的浏览器里，不上传、不写进代码。每次调 AI 之前都会先弹确认框，告诉你将调用哪个服务、将发送哪段文字，并要求勾选「这是我自己的原创文字」，不勾选不发送。

## 隐私与版权

- **数据只存本地**：全部内容只存在你浏览器的 IndexedDB 里，没有后端、没有账号、没有同步，不上传到任何服务器。
- **只处理自己的创作**：本应用不抓取、不爬取任何网站，不提供批量导入他人作品的功能；导入只接受你自己从本应用导出的 JSON。
- **原作只存摘要**：原作相关信息只允许你自己写的 200 字内短摘要，不存原作原文、截图或译文。
- **AI 有边界**：AI 只做一致性检查和提问式灵感激发，不模仿任何作者的文风，不续写、改写你的草稿，不用你的数据训练模型。
- 七条合规底线见 [`docs/PRINCIPLES.md`](docs/PRINCIPLES.md)，阶段 7 自查报告见 [`docs/AUDIT-2026-11-17.md`](docs/AUDIT-2026-11-17.md)。

## 项目结构

```
src/
  lib/        数据层（Dexie）、AI 调用、提示词、导出导入
  features/   潮位 / 贝壳盒 / 设定卡 / 伏笔 / AI / 设置区
  styles/     设计 token 与基础样式
docs/         合规底线、范围、设计、技术方案、自查报告
```

技术：React + Vite + TypeScript + Dexie（IndexedDB），无后端，静态托管即可运行。
