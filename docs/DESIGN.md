## 1. 配色（6 个，带名字与色值）

| 名字 | 色值 | 用途 |
| --- | --- | --- |
| 夜潮深青 | `#0E2B29` | 首页的水、主按钮、深色区块底 |
| 浅滩海玻璃绿 | `#8FBFAE` | 水面、次要强调、已回收以外的水下提示 |
| 泡沫白 | `#F5F6F2` | 页面底色（偏冷的白，不是暖奶油） |
| 湿沙灰褐 | `#6E6252` | 次要文字、分割线、标签 |
| 月光淡黄 | `#E9D9A6` | 只用在月亮和已回收的礁石上，很克制 |
| 深水墨 | `#1E2A28` | 正文、标题 |

对比度（已实算，WCAG AA 要求正文 4.5:1）：
- 正文深水墨 / 泡沫白：13.65:1
- 湿沙灰褐 / 泡沫白：5.48:1
- 月光淡黄 / 夜潮深青：10.70:1
- 泡沫白 / 夜潮深青：13.86:1
- 海玻璃绿 / 夜潮深青：7.33:1（只做水面与装饰，不做小字）

刻意避开的套路：不用暖奶油底（`#F4F1EA`）配赤陶色（`#D97757`），不用深黑底配荧光强调，不用渐变做装饰。

## 1b. 两个主题：深夜与白天

不另加新颜色，上面 6 个色在两个主题里换角色。这样设计系统只有一套 token，切换主题只是换赋值，不会养出两套样式。

| 角色 | 白天 | 深夜 |
| --- | --- | --- |
| 页面底色 | 泡沫白 `#F5F6F2` | 夜潮深青 `#0E2B29` |
| 正文 | 深水墨 `#1E2A28`（13.65:1） | 泡沫白 `#F5F6F2`（13.86:1） |
| 次要文字 | 湿沙灰褐 `#6E6252`（5.48:1） | 海玻璃绿 `#8FBFAE`（7.33:1） |
| 主色 / 首页的水 | 夜潮深青 `#0E2B29` | 海玻璃绿 `#8FBFAE`（水面比底色亮一档） |
| 月光 | 月光淡黄 `#E9D9A6`，只做月亮图标与已回收礁石的填充，不做文字（在白底上对比度不够） | 月光淡黄 `#E9D9A6`，月亮与已回收礁石（10.70:1，可做文字） |
| 分割线 | 湿沙灰褐 `#6E6252` | 湿沙灰褐只做分割线，不做文字（在深底上对比度不够） |

- 白天是浅滩正午：底色亮、水是深青的，礁石在水下是深青色模糊轮廓。
- 深夜是退潮的夜里：底色就是深青的夜，水面是海玻璃绿的一线，月亮是淡黄的，礁石在水下几乎只剩轮廓，露出水面时才被月光照亮。
- 切换方式：默认跟随系统（`prefers-color-scheme`），用户可在设置页手动切“深夜 / 白天 / 跟随系统”，选择只存本机。理由：深夜写东西的人多，默认跟系统最省事；手动切一次就记住，不用每次调。
- 潮位首页的动效在两个主题下一样，只用 `transform` 和 `opacity`，600–900 毫秒缓出；减动态时两个主题都变静态。

## 2. 字体（两种，差异明显）

| 字体 | 用途 | 为什么 |
| --- | --- | --- |
| Noto Serif SC（衬线） | 首页那句“水下还有 N 块礁石”、页面标题、礁石标题 | 有月光下读信的感觉，负责氛围；中文全，笔画在手机上也稳 |
| Noto Sans SC（无衬线） | 正文、列表、按钮、标签、输入框 | 手机上好读，负责功能；与衬线差异一眼可见 |

规则：一个页面最多出现这两种；按钮与正文都用无衬线，不用全大写标签。
加载方式在阶段 4 定：优先本地子集化，不默认走外部字体 CDN（外部请求要能说明理由，见 PRINCIPLES 第 4 条）。

## 3. 布局思路（文字 + ASCII 草图）

通用规则：左对齐为主；内容不切成一模一样的圆角卡片，列表用细线分隔，条目之间用间距和字号分层级；不是序列的内容不加 01/02/03 编号；按钮写明会发生什么（如“保存灵感”），同一动作全流程用同一名称；空状态引导行动（如“还没有灵感，写下第一条吧”）。

```
┌─────────────────────┐

│                     │
│   ～～～～～～～～   │  海岸线：水位缓慢起伏
│  ～～～～～～～～～  │
│ ～～ ▲ ～～～ ▲ ～～ │  水下礁石：模糊轮廓 + 标题
│ ～～～～～～～～～～ │
│                     │
│ 水下还有 3 块礁石    │  全页只写这一句话（衬线）
│                     │
│ [潮位][贝壳][设定]  │  底部导航
│ [伏笔][设置]        │

```

- 每条未回收的伏笔是一块水下礁石，只显示模糊轮廓和标题，点击看详情。
- 把伏笔标为“已回收”时，水位轻轻下降，该礁石逐渐露出。这是全应用唯一的重点动效。
- 没有统计卡片、没有快捷入口堆叠，首页不兼做仪表盘。

## 4. 导航结构（手机端底部导航）

```
[潮位] [贝壳盒] [设定] [伏笔] [设置]
```

- 5 个入口，正好一手拇指够得着；第一批的四个核心功能各占一个，设置占一个。
- 第三批的月相、潮汐表、导出不另加底部入口，进“设置”页内的分区。理由：底部超过 5 个会挤，拇指也够不着；月相和潮汐表是偶尔看的东西，不需要常驻导航。
- 设置页最小版（阶段 5.4）只含 AI Key 填写；完整版（阶段 5.5）再加数据清空、导出入口、月相、潮汐表。

## 5. 唯一的记忆点：潮位首页

- 首页是一片抽象的海岸线，水位缓慢起伏。
- 每条未回收的伏笔是水下的一块礁石，只显示模糊轮廓和标题，点击可查看详情。
- 用户把伏笔标记为“已回收”时，水位轻轻下降，该礁石逐渐露出。这是全应用唯一的重点动效。
- 首页文字只写一句话：“水下还有 N 块礁石”。
- 动效只使用 `transform` 和 `opacity`，节奏缓慢，约 600–900 毫秒的缓出（`ease-out`，不用 `ease-in`，不用 `transition: all`）。
- 系统开启“减少动态效果”时，改为静态水位线加礁石数量，不做起伏、不做露出动画。

按 `emil-design-eng` 的动效四问核对过：要不要动——只在回收揭晓那一刻动，平时水位只是缓慢起伏；为什么动——让用户亲眼看到伏笔被收回来了；什么曲线——缓出；多快——600–900 毫秒，慢，但只动一次。

## 设计原则（全应用遵守）

- 只让潮位首页成为记忆点，其余部分保持安静克制。
- 动效只用于回应用户操作和上面那一个揭晓时刻，不给每个区块加淡入上滑，不给每张卡片加悬停动画。
- 不要把内容切成一模一样的圆角卡片；不要全大写标签；不要用渐变做装饰；不是序列的内容不加 01/02/03 编号。
- 潮汐化命名只改名字，不加额外特效：灵感速记叫“贝壳盒”，来源登记叫“月相”，进度叫“潮汐表”。
- 月相里的原作以灰色月相图标呈现，只显示名称和链接，不可编辑内容。
- 文案用白话，按钮写明会发生什么（如“保存灵感”），同一动作全流程用同一名称。空状态引导行动。
- 质量底线：手机优先，键盘焦点可见，文字对比度达标，尊重“减少动态效果”。

## 自查：如果这套方案换成别的应用也成立，说明太通用

第一稿确实有这个问题，我改了四处：

1. **湿沙灰褐改深了**：从 `#8A7B68` 改成 `#6E6252`。为什么：旧色在泡沫白底上对比度只有 3.78:1，小字不达标；新色 5.48:1，达标。这不是审美改动，是底线改动。
2. **泡沫白改冷了**：不用暖奶油 `#F4F1EA`，改用偏冷的 `#F5F6F2`。为什么：暖奶油配衬线标题是 AI 生成页最常见的套路，`frontend-design` 点名避开；冷白配深青才是夜潮，不是奶油。
3. **首页不是仪表盘**：第一稿差点写成“今日灵感数 + 伏笔统计 + 快捷入口”三张卡。为什么改：那是任何效率应用都能用的布局；改成一整片海岸线、一句话、礁石就是伏笔本身，这套布局只有拾潮成立。
4. **月光黄收起来了**：第一稿想拿淡黄做全站强调色。为什么改：强调色到处用就成了通用点缀；现在只准出现在月亮和已回收的礁石上，月光只照在“被收回来的东西”上，这才和“原作是月亮”那句隐喻扣上。
